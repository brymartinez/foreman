# Pull request

Title: conventional prefix plus what changed, under 72 characters. Example: `fix: retry push when the remote rejects a stale ref`.

Body, in this order:

1. **What changed.** Two to four sentences on the behavior, not a file-by-file tour.
2. **Why.** The problem from the issue, in one or two sentences.
3. **Validation.** Each command you ran and its result. Say what you checked by hand, if anything.
4. **Decisions.** Choices you made that a reviewer might question, one line each. Omit the section if there are none.
5. `Closes #N`

Write it plainly. No em dashes, no filler, no "This PR...". Skip Risks or Follow-ups sections unless something needs the reviewer's attention.
